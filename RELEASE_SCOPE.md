# Release scope

## Included

- 4HDP implementation and tests
- ASB/AIOS code required by the evaluation harness
- Oracle-free ASB tool-call adapter
- Exact semantic-audit prompt template
- Threshold and decision documentation
- Frozen case and memory-retrieval inputs
- Formal, benign, ablation, and adaptive experiment entry points
- Validators, synthetic examples, and limitation documentation
- Upstream licence and attribution
- Curated de-identified revision evidence for the selected results, with
  per-sample minimal outcomes, summaries, failure records, and hashes

## Excluded

- Unselected result CSV/JSON/JSONL files and full raw result dumps
- Raw audit and execution traces
- Full logs, interrupted batches, smoke outputs, and recovery archives
- Chroma and other local databases
- API keys, `.env`, and machine-specific configuration
- Manuscript and reviewer-response files
