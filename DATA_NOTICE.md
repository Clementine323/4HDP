# Data notice

The ASB-derived files in this repository contain third-party benchmark task
fixtures, including names, identifiers, and medical, legal, and financial
scenario text.

These materials are benchmark inputs retained for reproducibility. They are not
data collected by the 4HDP authors from users, study participants, or production
systems.

The provenance, pinned upstream revision, licence, and release-specific
modifications are documented in `THIRD_PARTY_NOTICES.md` and
`experiments/benchmarks/ASB/MODIFICATIONS.md`.

This repository does not intentionally include author personal information,
API credentials, private execution logs, or unpublished 4HDP experimental
result files.
